This is a very simple program that I made in the spring of 2024, for a grade 11 chemistry lab. 

The lab write-up included us calculating the molar heat of fusion of ice. Since that required a hefty formula, 
our chemistry teacher told us that we could use some sort of calculator, for example in Excel,
to double check our answer after we showed all of our work, as long as we made it ourselves. 
Since I was learning Python, I decided to make a simple little calculator. 
I was just a beginner programmer, so it wasn't anything fancy. No user interface, 
just input in, make the numbers go through my specific formula, and output out.

There's no control flow, no loops, no functions, so even then it felt a bit too rudimentary. 
But I was also so proud because this was the first project that I fully made myself, for myself. 
This wasn't an exercise or assignment with a guide, and it was something I was actually going to use in my life. 
Although it's a little bit messy and very basic, it showed me the power of programming and started my journey in this field.
